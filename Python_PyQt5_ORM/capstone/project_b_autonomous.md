## 1. 주제 선정 가이드

### "무엇을 만들지" 정하는 방법

다음 질문에 답해보세요:
1. **매일 반복하는 업무** 중 가장 귀찮은 것은 무엇인가요?
2. **엑셀로 관리하고 있는 데이터** 중 앱으로 바꾸면 편할 것은?
3. **여러 사람이 함께 관리해야 하는 정보**가 있나요?

### 주제 예시

| 주제 | 핵심 기능 | 난이도 |
|------|-----------|--------|
| 간이 CRM | 거래처 관리, 상담 이력, 다음 연락일 | ★★☆ |
| 거래처 관리 | 거래처 정보, 계약 현황, 담당자 | ★★☆ |
| 회의록 아카이브 | 회의 기록, 참석자, 액션 아이템 추적 | ★★☆ |
| 재고 관리 | 품목 등록, 입출고 기록, 재고 현황 | ★★★ |
| 교육 이수 관리 | 교육 과정, 이수자, 수료증 관리 | ★★☆ |
| 프로젝트 트래커 | 프로젝트 목록, 마일스톤, 진행률 | ★★★ |

## 2. 프로젝트 진행 단계

### 단계 1: 요구사항 정의 (Claude Code와 협업)

```
[나의 업무 설명]을 위한 데스크톱 앱의 PRD를 작성해줘.
기능 목록, 사용자 스토리, 비기능 요구사항을 포함해줘.
3단계 사용자 권한(admin/manager/user)도 고려해줘.
```

### 단계 2: 설계 (Claude Code와 협업)

```
이 PRD를 기반으로:
1. Mermaid ERD 다이어그램을 생성해줘
2. UI/Service/Repository/Model 계층으로 작업을 분해해줘
3. 각 작업은 Claude Code에서 한 번에 처리할 수 있는 크기로 나눠줘
```

### 단계 3: 구현 (Claude Code 주도, 학습자 검증)
- 모델 → Repository → Service → UI 순서로 구현
- 각 단계마다 Git 커밋
- 각 단계마다 코드 검증 (계층 분리, 보안 최소선 확인)

### 단계 4: 검증 (학습자 주도)
- pytest 테스트 작성 (최소 3개)
- 코드 리뷰 체크리스트 실행
- 엣지 케이스 테스트

### 단계 5: 배포
- SQLite로 개발 → PostgreSQL 전환 체험
- PyInstaller로 실행 파일 빌드
- 다른 환경에서 동작 확인
