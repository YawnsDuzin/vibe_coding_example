## 실습 2: 시그널/슬롯 추적하기

### 핵심 개념
시그널/슬롯은 PyQt5의 이벤트 처리 패턴입니다.

비유: **초인종(시그널)**을 누르면 → **문을 여는 동작(슬롯)**이 실행된다

```python
# 초인종(시그널) = button.clicked
# 문 여는 동작(슬롯) = self._on_login
# "초인종을 누르면 문을 열어라" = connect
self.login_btn.clicked.connect(self._on_login)
```

### Claude Code에 입력해보세요

```
app/ui/login_form.py에서 모든 시그널/슬롯 연결을 찾아줘.
"어떤 위젯의 어떤 시그널이 어떤 함수에 연결되어 있는지" 표로 정리해줘.
```

### 검증 포인트 ✓
- [ ] `clicked.connect(함수)` 구문의 의미를 설명할 수 있나요?
- [ ] 로그인 버튼을 클릭하면 어떤 함수가 실행되는지 찾을 수 있나요?
