> 데이터를 넣고 빼는 기본 개념(CRUD)을 익힙니다.

---

## 실습 1: 엑셀에서 데이터베이스로

### 왜 이걸 배우나요?
지금까지 엑셀로 관리하던 데이터를 데이터베이스로 옮기면:
- 여러 사람이 동시에 사용할 수 있습니다
- 데이터가 실수로 깨지는 것을 방지할 수 있습니다
- 조건에 맞는 데이터를 빠르게 찾을 수 있습니다

### Claude Code에 입력해보세요

```
내가 엑셀로 거래처 정보를 관리하고 있어.
시트 1에는 거래처 목록(회사명, 담당자, 전화번호, 이메일),
시트 2에는 거래 내역(날짜, 거래처, 품목, 금액)이 있어.

이걸 데이터베이스 테이블로 바꾸려면 어떻게 해야 하는지 설명해줘.
Mermaid ERD 다이어그램으로 보여줘.
```

### 핵심 개념

| 엑셀 용어 | DB 용어 | 설명 |
|-----------|---------|------|
| 시트 | 테이블(Table) | 데이터를 담는 표 |
| 열(컬럼) | 컬럼(Column) | 데이터의 항목 (이름, 이메일 등) |
| 행(로우) | 로우(Row)/레코드 | 데이터 한 건 |
| VLOOKUP | JOIN | 다른 테이블의 데이터를 연결 |

## 실습 2: ERD 설계하기

### Claude Code에 입력해보세요

```
"할 일 관리 앱"에 필요한 테이블을 설계해줘.
요구사항:
- 사용자는 여러 할 일을 가질 수 있다
- 각 할 일은 제목, 설명, 완료 여부, 우선순위, 마감일이 있다
- 할 일은 카테고리로 분류할 수 있다 (1개의 카테고리에 여러 할 일)

Mermaid ERD 다이어그램으로 보여주고, 각 테이블의 역할을 설명해줘.
```

### 검증해보세요

```
이 ERD에서 User와 Task의 관계가 올바른지 확인해줘.
한 Task가 여러 User에게 동시에 할당될 수도 있다면 ERD가 어떻게 바뀌어야 하는지도 보여줘.
```

## 실습 3: SQL CRUD 체험하기

### Claude Code에 입력해보세요

```
위에서 설계한 ERD를 SQLite CREATE TABLE 문으로 변환해줘.
그런 다음 예시 데이터 3개를 INSERT하고,
다음 쿼리를 보여줘:
1. 모든 할 일 조회
2. 완료되지 않은 할 일만 조회
3. 특정 사용자의 할 일 조회

각 쿼리가 무엇을 하는지 주석으로 설명해줘.
```

### 검증 포인트 ✓
- [ ] CREATE TABLE이 "테이블을 만드는 명령"이라는 것을 이해하나요?
- [ ] SELECT, INSERT, UPDATE, DELETE 각각의 역할을 설명할 수 있나요?
- [ ] 1:N 관계를 "한 명의 사용자가 여러 할 일을 가진다"로 설명할 수 있나요?
