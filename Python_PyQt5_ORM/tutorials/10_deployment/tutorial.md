# 튜토리얼 10: 배포와 마무리

> **이 단원에서 배우는 것**: 만든 앱을 다른 사람에게 전달할 수 있는 실행 파일로 만들고,
> SQLite에서 PostgreSQL로 전환하여 ORM의 가치를 체감합니다.

---

## 왜 이걸 배우나요?

지금까지 만든 앱은 Python이 설치된 컴퓨터에서만 실행됩니다.
PyInstaller를 사용하면 **Python을 설치하지 않은 컴퓨터에서도 실행할 수 있는 파일**을 만들 수 있습니다.

비유: 레시피(소스 코드)를 직접 요리(실행)하려면 주방 도구(Python)가 필요하지만,
완성된 도시락(실행 파일)은 누구나 바로 먹을(실행할) 수 있습니다.

## 실습 2: SQLite → PostgreSQL 전환

### 왜 이걸 체험하나요?
ORM의 가장 큰 장점인 **DB 독립성**을 직접 체감합니다.
".env 파일 하나만 바꾸면 다른 DB에서 동작한다!"를 경험합니다.

### Claude Code에 입력해보세요

#### 2-1. 전환 준비
```
.env 파일에서 DB_TYPE을 postgresql로 변경하고,
PostgreSQL 접속 정보를 설정해줘.
현재 SQLite 데이터를 PostgreSQL로 옮기는 방법도 설명해줘.
```

#### 2-2. 마이그레이션 실행
```
PostgreSQL 데이터베이스에 Alembic 마이그레이션을 실행하는 명령을 알려줘.
실행 전에 확인해야 할 사항도 알려줘.
```

### 핵심 체감 포인트

```
# .env 파일에서 이것만 바꿨습니다:
DB_TYPE=sqlite   →   DB_TYPE=postgresql

# Python 코드는 한 줄도 바꾸지 않았습니다!
# 그런데 앱이 PostgreSQL에서 동작합니다!
```

이것이 ORM(SQLAlchemy)과 `.env` 설정 분리의 진정한 가치입니다.
