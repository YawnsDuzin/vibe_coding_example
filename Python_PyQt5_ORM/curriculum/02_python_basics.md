| 항목 | 내용 |
|------|------|
| **주차** | 2주 (3~4회차) |
| **예상 시간** | 6시간 (강의 2h + 실습 4h) |
| **보일러플레이트 연결** | `app/core/`, `app/models/` 코드 읽기 |

---

## 학습 목표 (3개)

1. 변수, 함수, 클래스의 개념을 이해하고 코드에서 식별할 수 있다
2. 보일러플레이트 코드를 읽고 "이 코드가 무엇을 하는지" 자기 말로 설명할 수 있다
3. 데이터 흐름(입력 → 처리 → 출력)을 코드에서 추적할 수 있다

---

## 주요 내용

### 2.1 변수와 데이터 타입
- 변수: "이름이 붙은 상자" — 값을 넣고 꺼내는 것
- 기본 타입: 문자열(`str`), 숫자(`int`, `float`), 불리언(`bool`)
- 리스트: "여러 개의 상자를 순서대로 나열"
- 딕셔너리: "라벨이 붙은 상자들의 모음"

### 2.2 함수
- "입력을 받아 → 처리하고 → 결과를 돌려주는 기계"
- `def`, 파라미터, 반환값(`return`)
- 보일러플레이트 예시: `hash_password()`, `verify_password()`

### 2.3 클래스
- "설계도(클래스)로 만든 제품(객체)"
- `class`, `__init__`, `self`
- 보일러플레이트 예시: `User`, `Role`, `CurrentUser`

### 2.4 임포트와 모듈
- `from app.core.config import APP_NAME` 읽는 법
- 모듈: "기능별로 분류된 파일"
- 패키지: "모듈을 담은 폴더"

### 2.5 코드 읽기 실전
- 보일러플레이트의 `config.py`, `auth.py` 코드를 한 줄씩 읽기
- "이 줄이 없으면 무슨 일이 생길까?" 질문 던지기

```
for 루프와 리스트 컴프리헨션의 차이를 간단한 예제로 보여줘. 각각의 장단점도 알려줘.
```

## 자주 만나는 함정

### 함정 1: "코드를 외워야 하나요?"
- **증상**: 문법을 암기하려 함 → 좌절
- **완화법**: "구문은 Claude Code가 씁니다. 여러분은 읽고 검증하면 됩니다"
  - 비유: "영어 원서를 읽을 줄 알면 되지, 직접 소설을 쓸 필요는 없다"
  - 읽기 연습에 시간의 80%를 투자

### 함정 2: "self가 뭔데요?"
- **증상**: 클래스에서 `self`가 나올 때마다 혼란
- **완화법**: "self = 지금 이 객체 자신"이라는 비유
  - "자동차가 '내 속도(self.speed)'를 말하는 것"
  - 당장 완벽히 이해하지 못해도 OK — 패턴으로 인식하면 충분
