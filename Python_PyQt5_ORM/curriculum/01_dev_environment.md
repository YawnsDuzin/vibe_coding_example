| 항목 | 내용 |
|------|------|
| **주차** | 1주 (1~2회차) |
| **예상 시간** | 6시간 (강의 2h + 실습 4h) |
| **보일러플레이트 연결** | 프로젝트 전체 구조 탐색, 환경 설정 |

---

## 학습 목표 (3개)

1. 파일시스템과 경로 개념을 이해하고, 터미널에서 기본 탐색을 할 수 있다
2. Git의 커밋·브랜치·되돌리기 개념을 이해하고, Claude Code로 Git 작업을 수행할 수 있다
3. 가상환경(venv)과 패키지 관리(pip)의 필요성을 체감하고, 프로젝트 환경을 설정할 수 있다

---

## 주요 내용

### 1.1 파일시스템과 경로
- 절대 경로 vs 상대 경로
- 디렉토리 구조 읽기 (보일러플레이트의 `app/` 구조 탐색)
- 확장자의 의미 (.py, .env, .md, .qss)

### 1.2 터미널 기초
- `cd`, `ls`, `pwd`, `mkdir` — Claude Code에서 직접 실행
- "터미널은 파일 탐색기의 텍스트 버전"이라는 비유

### 1.3 Git = 저장 지점
- 커밋: "게임의 세이브 포인트"
- 브랜치: "평행 세계"
- 되돌리기: "세이브 포인트로 돌아가기"
- `git status`, `git add`, `git commit`, `git log`

### 1.4 가상환경과 패키지
- venv: "이 프로젝트만을 위한 전용 도구 상자"
- pip: "도구 상자에 도구를 넣는 명령"
- requirements.txt: "도구 목록표"
- **왜 필요한가**: 프로젝트마다 다른 도구 버전이 필요할 수 있음

| venv 생성·패키지 설치 | 왜 가상환경이 필요한지 설명 가능 |

```

```
app/core/ 디렉토리에 있는 파일들이 각각 무슨 일을 하는지 간단히 설명해줘

```
지금 변경된 파일 목록을 확인하고, "환경 설정 완료"라는 메시지로 커밋해줘
```

```
Git 커밋 히스토리를 보여주고, 각 커밋이 무엇을 했는지 요약해줘
```

### 환경 설정
```
venv를 만들고 requirements.txt에서 패키지를 설치해줘
```

```
.env.example을 복사해서 .env 파일을 만들어줘. 기본 SQLite 설정으로 해줘.
```

## 자주 만나는 함정

### 함정 1: "가상환경, 왜 필요해요? 그냥 설치하면 되잖아요"
- **증상**: venv 없이 `pip install` → 다른 프로젝트와 패키지 충돌
- **완화법**: 일부러 충돌 상황을 만들어 체험시킴
  - "A 프로젝트는 SQLAlchemy 1.4, B 프로젝트는 2.0이 필요하다면?"
  - 각 프로젝트가 '자기만의 도구 상자'를 가져야 하는 이유를 체감

### 함정 2: "터미널이 무서워요"
- **증상**: 까만 화면에 거부감, 오타 하나에 패닉
- **완화법**: Claude Code를 통해 명령어를 실행하므로 직접 입력 최소화
  - "이 디렉토리의 파일 목록을 보여줘"라고 자연어로 요청하면 됨
  - 터미널은 "타이핑하는 파일 탐색기"라는 비유 반복
