# 단원 10: 배포와 마무리

| 항목 | 내용 |
|------|------|
| **주차** | 10주 (19~20회차) |
| **예상 시간** | 6시간 (강의 2h + 실습 4h) |
| **보일러플레이트 연결** | 전체 프로젝트 빌드·배포 |

---

## 학습 목표 (3개)

1. PyInstaller로 Python 앱을 실행 파일(.exe)로 패키징하고 배포할 수 있다
2. SQLite → PostgreSQL 전환을 수행하고, ORM 덕분에 코드 변경이 최소임을 체감할 수 있다
3. 캡스톤 B(자율 프로젝트)의 최종 배포를 완료할 수 있다

---

## 주요 내용

### 10.1 PyInstaller 빌드
- PyInstaller = "Python 프로젝트를 실행 파일 하나로 묶는 도구"
- .spec 파일: 빌드 설정 파일 (어떤 파일을 포함할지, 아이콘 설정 등)
- 데이터 파일 포함: QSS, .ui, 아이콘 등을 빌드에 포함하는 방법
- 빌드 후 테스트: 빌드된 실행 파일이 정상 동작하는지 확인

### 10.2 SQLite → PostgreSQL 전환
- `.env` 파일에서 `DB_TYPE=postgresql`로 변경
- PostgreSQL 접속 정보 설정
- Alembic 마이그레이션 실행
- **핵심 체감**: "코드를 한 줄도 안 바꿨는데 다른 DB에서 동작한다!"
- ORM + DB 독립성의 가치를 직접 경험

### 10.3 배포 체크리스트
- [ ] 실행 파일이 정상 동작하는가
- [ ] DB 파일이 올바르게 포함되었는가 (SQLite의 경우)
- [ ] .env 파일의 민감 정보가 빌드에 포함되지 않았는가
- [ ] 필요한 리소스(QSS, 아이콘)가 모두 포함되었는가
- [ ] 다른 컴퓨터에서도 실행 가능한가

### 10.4 캡스톤 B 발표
- 자기 업무 문제를 해결하는 데스크톱 앱 시연
- 학습 여정 회고: 프롬프트 일지, 커스텀 Skills 목록 발표

## 자주 만나는 함정

### 함정 1: "빌드했는데 실행하면 에러 나요"
- **증상**: PyInstaller 빌드 성공 → 실행 시 ModuleNotFoundError 또는 리소스 미포함
- **완화법**: .spec 파일에서 `datas`와 `hiddenimports` 확인
  - QSS 파일, .ui 파일, 아이콘은 `datas`에 명시적으로 포함
  - `--onefile` vs `--onedir` 차이 이해

### 함정 2: "PostgreSQL 연결이 안 돼요"
- **증상**: PostgreSQL 미설치 또는 접속 정보 오류
- **완화법**: PostgreSQL 설치·설정 가이드를 단계별로 제공
  - Docker로 PostgreSQL 실행하는 것은 커리큘럼 스코프 밖이지만, 로컬 설치 가이드 제공
  - .env의 접속 정보가 정확한지 체크리스트로 확인
