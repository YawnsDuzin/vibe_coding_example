## 학습 순서 추천

1. **1주차**: Git 간편 안내서 → 점프 투 파이썬 1~4장
2. **2주차**: 점프 투 파이썬 5~6장 (함수, 클래스)
3. **3주차**: W3Schools SQL → SQL 첫걸음
4. **4주차**: SQLAlchemy 한국어 가이드
5. **5주차**: PyQt5 Tutorial (위키독스)
6. **6주차~**: Claude Code 공식 문서 참고하며 실습
