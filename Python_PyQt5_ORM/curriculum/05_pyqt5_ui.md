## 주요 내용

### 5.1 위젯(Widget)이란?
- "화면에 보이는 모든 것" — 버튼, 입력칸, 라벨, 체크박스 등
- 주요 위젯: `QPushButton`, `QLineEdit`, `QLabel`, `QComboBox`, `QTableWidget`
- 보일러플레이트의 `login_form.py`에서 실제 위젯 확인

### 5.2 레이아웃(Layout)
- "위젯을 배치하는 방법"
- `QVBoxLayout`: 세로로 쌓기 (V = Vertical)
- `QHBoxLayout`: 가로로 나열 (H = Horizontal)
- 중첩: 레이아웃 안에 레이아웃 넣기
- `QStackedWidget`: 여러 페이지를 겹쳐놓고 하나만 보여주기

### 5.3 시그널/슬롯 (Signal/Slot) ★
- **핵심 개념**: "이벤트가 발생하면(Signal) → 이 함수를 실행해라(Slot)"
- 비유: "초인종(Signal)을 누르면 → 문을 열어주는 동작(Slot)이 실행된다"
- 예시: `button.clicked.connect(self._on_login)` → "버튼 클릭 시 `_on_login` 실행"
- **커스텀 시그널**: 위젯 간 통신 (예: `login_success` 시그널)

### 5.4 Qt Designer 활용
- .ui 파일: 드래그앤드롭으로 만든 UI 설계 파일
- `pyuic5`: .ui → .py 변환 도구
- Claude Code로 .ui 파일에 시그널/슬롯 연결 코드 생성

### 5.5 UI-로직 분리
- UI 코드에서 직접 DB 접근 금지!
- 흐름: UI(버튼 클릭) → Service(비즈니스 로직) → Repository(DB 접근)
- 보일러플레이트의 `login_form.py` → `auth_service.py` → `user_repository.py` 흐름 추적

## 자주 만나는 함정

### 함정 1: "시그널/슬롯이 뭔지 모르겠어요"
- **증상**: `clicked.connect(func)` 문법이 추상적으로 느껴짐
- **완화법**: 실생활 비유로 반복 설명
  - 시그널 = 벨 소리 / 슬롯 = 벨 소리를 들었을 때 하는 행동
  - `button.clicked` = "버튼이 울리는 벨"
  - `.connect(self._on_login)` = "이 벨이 울리면 `_on_login`을 실행해"
  - 보일러플레이트의 모든 connect를 찾아서 "벨-행동" 매핑표를 만들기

### 함정 2: "위젯이 안 보여요"
- **증상**: 위젯을 만들었는데 화면에 나타나지 않음
- **완화법**: 레이아웃에 `addWidget()`으로 추가했는지 확인
  - "방(레이아웃)에 가구(위젯)를 안 넣으면 빈 방이 보이는 것"
