## 1. 커리큘럼 개요

| 항목 | 내용 |
|------|------|
| **총 학습 시간** | 약 60~80시간 (10주 × 주 2회 × 3시간 + 자율 실습) |
| **총 주차** | 10주 (20회차) |
| **1회차 분량** | 3시간 (강의 1시간 + 실습 2시간) |
| **최종 결과물** | 학습자가 자기 업무에 사용할 수 있는 PyQt5 데스크톱 앱 1개 |
| **운영 형태** | 블렌디드 (대면 실습 + 온라인 자율학습 + Claude Code 활용) |

## 4. 핵심 설계 원칙

### 4.1 Claude Code-First
모든 작업(코드, 문서, 설정, 디버깅, 학습)을 Claude Code 안에서 수행합니다.

### 4.2 구문 작성 X, 구조 이해 O
코드를 직접 작성하는 것이 아니라, 구조를 이해하여 AI에게 정확히 지시할 수 있는 능력을 키웁니다.

### 4.3 보일러플레이트 기반
백지에서 시작하지 않습니다. 표준 보일러플레이트를 읽고 → 이해하고 → 확장하는 방식입니다.

### 4.4 계층 분리 체화
UI → Service → Repository → Model 구조를 첫날부터 일관되게 유지합니다.

### 4.5 검증 습관 내재화
AI가 생성한 코드를 반드시 읽고 → 실행하고 → 확인하는 루틴을 모든 실습에 삽입합니다.

## 5. 의도적으로 제외하는 주제와 이유

| 제외 주제 | 이유 |
|-----------|------|
| 비동기/멀티스레딩 고급 | GUI 이벤트 루프와 충돌 가능성 높음. 비개발자 난이도 초과 |
| Qt MVC 프레임워크 | 자체 MVC는 학습 곡선이 가파르고, 커리큘럼의 계층 분리와 충돌 |
| PostgreSQL 튜닝 | DBA 영역. 비개발자는 "연결하고 사용"까지만 필요 |
| Docker | 배포 편의성은 있으나, 비개발자에게 또 하나의 진입장벽 추가 |
| CI/CD | 1인 개발 시나리오에서 불필요. 팀 개발 경험 전제 |
| 클라우드 배포 | PyInstaller 로컬 배포에 집중. 클라우드는 별도 과정 |
| 타입힌트 고급 | Generic, Protocol 등은 비개발자 혼란 유발 |
| 디자인 패턴 이론 | 패턴 이름을 아는 것보다 계층 분리를 체화하는 것이 우선 |
| 웹 프레임워크 (Flask, Django) | 데스크톱 앱에 집중. 웹은 별도 트랙 |
| 머신러닝/데이터 분석 | 별도 도메인. 이 커리큘럼의 스코프 밖 |

## 6. 운영 설계

### 6.1 블렌디드 포맷 권장안
| 구분 | 형태 | 비율 |
|------|------|------|
| 대면 강의 | 개념 설명 + 라이브 데모 | 30% |
| 대면 실습 | 보일러플레이트 확장, 페어 프로그래밍 | 40% |
| 온라인 자율 | Claude Code와 1:1 실습, 캡스톤 작업 | 30% |

### 6.2 학습자가 막혔을 때 복구 경로
1. **1차**: Claude Code에 질문 (프롬프트 템플릿 제공)
   - "이 에러 메시지가 무엇을 의미하는지 설명해줘: [에러 내용]"
   - "지금 내 코드에서 문제가 있는 부분을 찾아줘"
2. **2차**: 커리큘럼 FAQ 문서 참조
3. **3차**: 조교/강사에게 에스컬레이션
   - 기준: Claude Code와 3회 이상 시도했으나 해결 안 되는 경우
   - 학습자가 시도한 프롬프트와 결과를 함께 공유

### 6.3 체크포인트
각 단원 종료 시 **자가진단 체크리스트**로 다음 단원 진행 가능 여부를 판단합니다.
체크리스트를 70% 이상 충족하면 다음 단원으로 진행, 미달 시 보충 실습을 제공합니다.
