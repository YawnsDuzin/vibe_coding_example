# /review

코드 리뷰와 품질 검증을 수행하는 Skill입니다.

## 용도
지정한 파일이나 최근 변경사항에 대해 코드 리뷰를 수행하고, 잠재적 문제를 찾아냅니다.

## 실행 내용

다음 관점으로 코드를 검토합니다:

1. **계층 분리 준수**
   - UI에서 직접 DB 접근하지 않는가?
   - Service를 거치지 않고 Repository를 직접 호출하지 않는가?

2. **보안 최소선**
   - 비밀번호 평문 저장 없는가?
   - SQL 인젝션 가능성 없는가? (ORM 바인딩 변수 사용)
   - .env에 시크릿이 잘 분리되었는가?

3. **코드 품질**
   - session.commit() 누락 없는가?
   - 에러 처리가 적절한가?
   - 불필요한 import나 미사용 코드 없는가?

4. **테스트 커버리지**
   - 핵심 비즈니스 로직에 테스트가 있는가?
   - 엣지 케이스가 처리되었는가?

## 출력 형식

```
## 코드 리뷰 결과

### 문제점 (심각도순)
1. [심각] ...
2. [주의] ...
3. [참고] ...

### 잘 된 점
- ...

### 개선 제안
- ...

### 테스트 필요 여부
- ...
```
