# /init-project

프로젝트 초기 환경을 한 번에 설정하는 Skill입니다.

## 용도
새 프로젝트를 시작할 때 가상환경 생성, 패키지 설치, Git 초기화, .env 파일 생성을 자동으로 수행합니다.

## 실행 내용

다음 작업을 순서대로 수행하세요:

1. **가상환경 생성**: `python -m venv venv` 실행
2. **가상환경 활성화 확인**: venv가 정상 생성되었는지 확인
3. **패키지 설치**: `pip install -r requirements.txt` 실행
4. **환경 변수 파일 생성**: `.env.example`을 복사하여 `.env` 파일 생성 (이미 있으면 건너뜀)
5. **Git 초기화**: Git 저장소가 아니면 `git init` 실행, `.gitignore` 확인
6. **데이터 디렉토리 생성**: `data/`, `logs/` 디렉토리 생성
7. **결과 보고**: 각 단계의 성공/실패 여부를 요약

## 사용되는 단원
- 단원 1: 기초 IT 지식 (개발 환경 설정)

## 주의사항
- 기존 venv가 있으면 덮어쓰지 않고 건너뜁니다
- .env 파일에 민감 정보가 포함될 수 있으므로 Git에 커밋하지 않습니다
