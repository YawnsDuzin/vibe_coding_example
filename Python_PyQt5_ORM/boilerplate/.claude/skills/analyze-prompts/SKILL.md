# /analyze-prompts

프롬프트 로그를 분석하여 반복 패턴을 발견하고 Skill 후보를 추천하는 Skill입니다.

## 용도
`.claude/prompt-log.jsonl`에 축적된 프롬프트 로그를 분석하여, 자주 반복되는 패턴을 찾고 커스텀 Skill로 만들 만한 후보를 추천합니다.

## 실행 내용

1. **로그 파일 읽기**: `.claude/prompt-log.jsonl` 파일을 읽습니다
2. **패턴 분석**: 프롬프트의 의도별 분류 (코드 생성, 설명 요청, 디버깅, 문서 작성 등)
3. **빈도수 집계**: 유사한 패턴의 빈도를 집계합니다
4. **Skill 후보 추천**: 빈도 3회 이상인 패턴을 Skill 후보로 추천
5. **SKILL.md 초안 생성**: 각 후보에 대한 SKILL.md 초안을 작성

## 출력 형식

```
## 프롬프트 분석 결과
- 총 프롬프트 수: N개
- 분류별 분포: (표)

## Skill 후보 추천
### 후보 1: /<이름>
- 빈도: N회
- 패턴: (반복되는 프롬프트의 공통 구조)
- SKILL.md 초안: (파일 내용)
```
