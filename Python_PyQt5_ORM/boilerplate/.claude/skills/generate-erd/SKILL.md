# /generate-erd

자연어 요구사항을 ERD와 DDL로 변환하는 Skill입니다.

## 용도
업무 요구사항을 자연어로 설명하면, Mermaid ERD 다이어그램과 SQL DDL을 자동 생성합니다.

## 실행 내용

사용자의 요구사항을 분석하여 다음을 순서대로 수행하세요:

1. **엔티티 도출**: 요구사항에서 관리할 대상(테이블)을 식별
2. **속성 정의**: 각 엔티티의 컬럼과 데이터 타입을 결정
3. **관계 설정**: 엔티티 간 관계(1:N, N:M)를 결정하고 FK 설정
4. **ERD 생성**: Mermaid erDiagram 형식으로 다이어그램 출력
5. **DDL 생성**: SQLite CREATE TABLE 문 출력 (한국어 주석 포함)
6. **관계 설명**: 각 관계가 무엇을 의미하는지 비개발자 언어로 설명

## 출력 형식

```
## 엔티티 목록
- (각 테이블의 역할 설명)

## ERD (Mermaid)
(Mermaid erDiagram 코드)

## DDL (CREATE TABLE)
(SQL DDL 코드, 주석 포함)

## 관계 설명
- (각 관계를 비개발자가 이해할 수 있게 설명)
```

## 사용되는 단원
- 단원 3: 데이터 모델링과 SQL 기초
- 단원 6: 요구사항 → 설계
