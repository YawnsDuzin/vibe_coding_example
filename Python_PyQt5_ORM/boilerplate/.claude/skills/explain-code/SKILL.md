# /explain-code

코드를 비개발자 눈높이로 설명하는 Skill입니다.

## 용도
선택한 코드 블록이나 파일의 내용을 비개발자가 이해할 수 있는 수준으로 한 줄씩 해설합니다.

## 실행 내용

사용자가 지정한 코드에 대해 다음을 수행하세요:

1. **전체 요약**: 이 코드가 전체적으로 무엇을 하는지 1-2문장으로 요약
2. **줄별 해설**: 각 핵심 라인에 대해:
   - 이 줄이 하는 일을 일상 언어로 설명
   - 비개발자가 헷갈릴 수 있는 용어에는 비유를 추가
   - 예: `session.commit()` → "은행에서 거래를 확정짓는 것과 같습니다"
3. **데이터 흐름**: 데이터가 코드 안에서 어떻게 이동하는지 설명
4. **주의 포인트**: 이 코드에서 비개발자가 특히 주의해야 할 부분

## 출력 형식

```
## 전체 요약
(1-2문장 요약)

## 줄별 해설
- 3번째 줄: `코드` → 설명
- 5번째 줄: `코드` → 설명
...

## 데이터 흐름
(입력 → 처리 → 출력 흐름 설명)

## 주의 포인트
- (비개발자가 놓치기 쉬운 포인트)
```

## 사용되는 단원
- 단원 2: Python 기본 문법 (코드 읽기 연습)
- 전체 단원에서 AI 산출물 검증 시 활용

## 주의사항
- 전문 용어를 사용할 때는 반드시 괄호 안에 쉬운 설명을 병기
- 코드를 "외우세요"가 아니라 "이해하세요" 톤으로 설명
