# /plan-feature

기능 설명을 PRD + ERD + 작업 분해로 변환하는 Skill입니다.

## 용도
하나의 기능에 대한 자연어 설명을 입력하면, PRD, ERD, 계층별 작업 분해를 한 번에 생성합니다.

## 실행 내용

1. **PRD 작성**:
   - 배경/목표
   - 사용자 스토리 (3~5개)
   - 기능 목록 (필수/선택 구분)
   - 비기능 요구사항

2. **ERD 생성**:
   - 필요한 테이블과 관계를 Mermaid erDiagram으로

3. **계층별 작업 분해 (To-do)**:
   - Model 작업: 모델 생성, 마이그레이션
   - Repository 작업: CRUD 메서드
   - Service 작업: 비즈니스 로직
   - UI 작업: 화면 구현, 시그널/슬롯
   - 각 작업은 "Claude Code에 하나의 프롬프트로 처리할 수 있는 크기"

## 사용되는 단원
- 단원 6: 요구사항 → 설계
- 캡스톤 프로젝트
