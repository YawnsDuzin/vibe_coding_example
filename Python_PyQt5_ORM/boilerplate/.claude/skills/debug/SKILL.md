# /debug

에러를 체계적으로 분석하고 해결하는 디버깅 Skill입니다.

## 용도
에러 로그나 현상 설명을 입력하면, 원인 분석부터 수정 코드 제안까지 단계별로 안내합니다.

## 실행 내용

1. **에러 분류**: 에러 종류 식별 (Traceback이 있으면 아래에서 위로 분석)
2. **원인 분석**: 가능한 원인 목록 (확률 높은 순서)
3. **수정 제안**: 각 원인에 대한 수정 코드 제시
4. **확인 방법**: 수정 후 정상 동작을 확인하는 방법
5. **재발 방지**: 같은 문제가 다시 발생하지 않도록 하는 조치

## 입력 형식
에러 로그 또는 현상 설명을 자유롭게 입력합니다.

에러 로그가 있으면:
```
[에러 Traceback 전체 붙여넣기]
```

에러 없이 동작이 이상하면:
```
현상: [무엇이 잘못되었는지]
기대 결과: [원래 어떻게 되어야 하는지]
재현 방법: [어떻게 하면 이 문제가 발생하는지]
```
